# Kaisutee — Editable Hero

Replace only these files in the existing repository:
- index.html
- app.js
- styles.css
- .pages.yml

Do NOT replace `data/` or `public/media/`.

After committing `.pages.yml`, Pages CMS > Site Settings will have:
- Name
- Hero Title
- Tagline
- Main Page Cover
- Profile Image
- Biography
- Hero Primary Button / Link
- Hero Secondary Button / Link
- social/contact fields

The Hero Title, tagline, biography, buttons and image are loaded from `data/site.json`.
The Navbar Name is loaded from the same Site Settings Name field.
